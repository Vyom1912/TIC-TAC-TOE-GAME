# ❌⭕ Tic Tac Toe

The classic two-player **Tic Tac Toe** game in the browser. Players X and O take turns; the first to line up three in a row wins.

## ✨ Features

- Two-player game on a 3×3 board
- Shows whose turn it is
- Detects wins across rows, columns and diagonals
- Displays the winner
- **Reset** button to start a new game

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
